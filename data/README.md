# Flood Inventory

This directory contains the historical flood and pseudo-non-flood locations collected for the **Tashkent Urban Flood Susceptibility Mapping** project.

The current dataset includes:
- **11 documented flood points**, identified through publicly available news reports, photographs, videos, and other sources.
- **22 pseudo-non-flood points**, selected from locations without documented flooding in the reference data.

The points are used as training and testing samples for the Random Forest and Support Vector Machine models.

## Project Status

**Data collection and refinement are ongoing.** Future work focuses on expanding the flood inventory, improving the geographic accuracy and reliability of documented flood locations, and refining the selection of pseudo-non-flood points.

**Note:** Pseudo-non-flood points do not necessarily represent locations that have never flooded; they indicate locations where flooding was not documented in the reference data.
