# Google Earth Engine Scripts

This directory contains the Google Earth Engine (GEE) JavaScript scripts developed for the **Tashkent Urban Flood Susceptibility Mapping** project.

The scripts cover:
- **Predictor preparation:** Processing elevation, slope, Topographic Position Index (TPI), and land cover datasets.
- **Random Forest:** Model training, validation, and flood susceptibility mapping.
- **Support Vector Machine (SVM):** Model training, validation, and comparison with Random Forest.

The workflow uses historical flood and pseudo-non-flood observations alongside geospatial predictor variables to estimate relative urban flood susceptibility.

## Project Status

**The modeling workflow is under ongoing development.** Future improvements include expanding the flood inventory, refining predictor variables, improving model validation, and updating the susceptibility maps.

The current scripts and results represent preliminary research and may be revised as the project progresses.
